# SATURNO source voicebank

This source package is built from `_a_ga_za_da_ba.wav` and contains the five
detected units:

```text
a · ga · za · da · ba
```

The cuts are approximate, based on the silence boundaries in the recording.
They are intended as a tiny training fixture, not as a finished voicebank.
The SaltCase neural runtime still requires trained `acoustic.mlmodelc` and
`vocoder.mlmodelc` files before this package can produce audio.

The recording should only be redistributed when the rights holder has granted
permission for the repository and any resulting voicebank.
