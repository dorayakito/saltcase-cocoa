The next voice

A new synthesis direction.

SaltCase is building a local neural synthesis runtime around Core ML and its own .scvoice voicebank format. The editor already passes expressive musical events to the new engine boundary.

A trained neural voicebank is not bundled yet. The current SATURNO source fixture contains a, ga, za, da and ba for future model work.

Musical event→Acoustic model→Vocoder→Audio
